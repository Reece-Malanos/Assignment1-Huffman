# Assignment1-Huffman
This is the Repo for my Assignment 1 for Advanced Algorithms. The project i will attempt to create a huffman lossless data compression algorithm.

within the same folder as Assignment.cpp there must be a file called "test.txt", that is the only requirement. 

there are 6 options in the menu, 

1 will be to compress the text file, this will generate an output called "compressed.bin"
2 will be to decompress, it will use that compressed.bin to generate a "decompressed.txt" file
3 shows you the contents of the "test.txt"
4 compares the contents of "test.txt" and "decompressed.txt" byte by byte to ensure a match.
5 displays the contents of "decompressed.txt"
6 displays the size in bytes, of the test.txt and compressed.bin
7 closes the program.
