# Assignment1-Huffman
This is the Repo for my Assignment 1 for Advanced Algorithms. The project i will be Huffman Coding Compression.

The plan for this project is to create a simple Huffman Data compression algorithm. 

Then i'm going to make an interface so that i can pass in large TXT files and compress them for storage. 

My goal in mind is to build a tool that compresses AI chat conversations, such as large strings or long conversations, key words, characters so that previous messages can be reconstructed for later use and understanding.
